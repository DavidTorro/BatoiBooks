# 6.1. SPA

Vamos a hacer que no aparezcan a la vez todas las páginas de nuestra aplicación (la de ver los libros, el formulario y la de *about*). Para ello, en lugar de usar una librería de *router* que se encargara de todo vamos a construir nuestro propio enrutador simple.

Lo primero necesitaremos una forma de ocultar o mostrar cosas y para ello usaremos la regla que hayamos creado en el CSS para que se oculten la id en el formulario (en mis caso actúa sobre la clase `hidden` poniendo su propiedad `display` a **none**).

Una vez tenemos claro cómo ocultar elementos necesitamos enterarnos de que el usuario quiere navegar a otra página. Para ello podríamos poner escuchadores a cada uno de los enlaces del formulario pero va a ser más sencillo poner un escuchador para cuando cambia el *hash* de la URL con el evento [`hashchange`](https://developer.mozilla.org/es/docs/Web/API/Window/hashchange_event) de `window` (recordad que en el `href` de los elementos del menú hemos puesto como rutas `#...`).

Simplemente pondremos el escuchador y lo que deberá hacer es ocultar las "páginas" y mostrar sólo la solicitada. Con la de 'Añadir libro' además de mostrar el formulario deberá dejarlo vacío y preparado para añadir un nuevo libro incluso aunque se esté editando uno en este momento.

Podríamos poner el código del *router* en un nuevo fichero dentro de *services*.
